# Global Sustainable Energy Analysis | Power BI

A data analytics and business intelligence project exploring global sustainable energy indicators and presenting key trends through an interactive Power BI dashboard.

## Project Overview
This project analyses global sustainable energy data to identify patterns in renewable energy, electricity access, emissions and other sustainability indicators. The objective is to transform a real-world dataset into clear, decision-focused insights for stakeholders.

## Tools & Skills
- Power BI
- Power Query / data transformation
- Data cleaning and preparation
- Data visualisation
- Dashboard design
- KPI and trend analysis
- Stakeholder reporting

## Repository Contents
- `Global Sustainable Energy Final Power BI.pbix` – Power BI dashboard
- `global-data-on-sustainable-energy.csv` – source dataset
- `Global Sustainable Energy Data Analysis Power BI Technical Report Document.pdf` – technical report
- `Summary Excuetive Power Bi Report for Stake Hoklders (1).pdf` – stakeholder summary

## What This Project Demonstrates
This portfolio project demonstrates practical experience taking a raw dataset through analysis and presenting findings in a business-friendly Power BI format. It highlights skills relevant to Data Analyst, Reporting Analyst, BI Support and junior Business Intelligence roles.

## Key Focus Areas
The analysis is designed to help users compare countries, explore sustainability trends and interpret important energy-related measures through clear visual reporting.
